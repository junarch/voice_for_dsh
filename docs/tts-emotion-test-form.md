> 比基线"更温柔/更慢/更活泼/更凶"这种方向词 + "一点点/明显/非常"这种程度词。
> **对比方法**：先听每段文本的 `01-基线`（记下"没有指令时它本来是什么样"），

### 附：第一轮结论备忘（2026-08-20，供对比）

| 指令 | 你的第一轮听感 |
|---|---|
| 内嵌 [#标签]（放 text 里） | ❌ 被逐字读出来（确认必读，已禁用） |
| 温柔语气 | 好像温柔了一些（微弱） |
| 慢速语速（vv） | 慢了一点点（"用非常慢"才明显） |
| 慢速语速（小何） | 慢一点、有停顿感 |
| 俏皮语气 | 明快不少 |
| 东北话 | 听不出来（基本无效） |
| 组合（东北话+暧昧） | 暧昧听得出，东北话听不出 |
| 包裹形式 [#…] 放 context_texts | 特别慢（意外发现，值得再验） |
